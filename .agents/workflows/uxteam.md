---
description: UX improvement team coordinator (Researcher -> Designer -> Reviewer)
---

1. Run `/uxresearcher` to analyze the current state, UX patterns, and similar applications.
2. Run `/uxdesigner` to propose interface improvements based on the research.
3. Run `/uxreviewer` to evaluate the usability of the proposed improvements and identify risks.
4. Summarize the final UX recommendations and status for the user.

Workflow rules:
* run each agent once
* maximum steps: 3 agents + summary
* do not create loops
* focus on improving usability and interface clarity
